# Brand images

These files are optional. The app shows a clean fallback for each one that is missing, and picks the file up automatically as soon as you add it here (no code change).

| File | Where it appears | Export from Figma |
|---|---|---|
| `logo.png` (or any PNG, transparent background) | Top navigation, sidebar, landing footer | The red/green "Serene EduHealth" logo (top-left of every screen) |
| `serene-ai.png` | Sidebar "Serene AI" item, chat header, chat avatars | The round robot avatar next to "Serene AI" |
| `hero-students.png` | Landing page hero (bottom centre) | The three students with the 3D first-aid kit, chart and heartbeat icons |
| `login-student.jpg` | Left half of the sign in / onboarding screens | The photo of the smiling student on the sign-in screen |
| `activity-hygiene.jpg`, `activity-nutrition.jpg`, `activity-safety.jpg`, `activity-event.jpg` | Category cards on Health Activity Tracker | The four card photos |
| `course-1.jpg` ... `course-8.jpg` | Course cards on Training Library (number = course `id`) | The course card photos |

How to export: select the layer in Figma, open **Export** in the right panel, choose PNG (or JPG for photos) at 2x, then Export. Use the file names above.
